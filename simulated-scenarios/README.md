# Simulated scenarios

100 scripted **invoice-collections** phone calls (not driver negotiation).

Each case: starting invoice state, customer lines, what a good agent should do, which tools to fire, what is forbidden, pass/fail.

| File | Difference |
| --- | --- |
| `ordinal_collections_vapi_evals.json` | Agent turns written as English stage notes |
| `ordinal_collections_vapi_evals_hinglish.json` | Same 100 cases; agent turns written as spoken Hinglish |

No audio. Exam paper, not scores. Domain is AP collections, not middle-mile rates.
